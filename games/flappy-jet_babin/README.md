# 🚀 Flappy Cyber Jet

> An action-packed endless side-scroller built with pure HTML5 Canvas and Web Audio API for **ArcadeVerse (Nexus Spring of Code – Winter Edition 2026)**.

## 🕹️ Game Overview
Pilot a high-speed cyber jet through pulsating neon laser conduits in a futuristic space station sector. Control vertical thruster bursts with precision timing to navigate narrow gaps and set new sector records.

## ⚡ Technical Highlights
- **100% Native Web Technologies**: Pure HTML5 Canvas, CSS3, and Vanilla JavaScript. Zero external frameworks or bundlers.
- **Dynamic Physics Model**: Realistic gravity acceleration, jump momentum, and velocity-dependent craft pitch rotation.
- **Procedural Particle Systems**: Real-time exhaust smoke trails and thruster blast effects rendered dynamically.
- **Zero-Latency Web Audio API**: Procedural sound synthesis generating thrust, scoring tones, and collision alerts without external audio files.
- **Persistent High Scores**: Stores sector records locally via the browser's `localStorage` API.
- **Multi-Device Input Handling**: Responsive controls supporting keyboard `Space`, mouse clicks, and touch taps on mobile screens.

## 🎮 Controls
| Action | Input |
|---|---|
| **Engage Thrusters** | `Spacebar` / Mouse Click / Touch Screen Tap |
| **Toggle Audio** | Speaker button in top header |
