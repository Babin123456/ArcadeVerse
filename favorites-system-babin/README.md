# ❤️ ArcadeVerse Favorites & Quick Launch System

> A lightweight client-side bookmarking module that allows players to save favorite games with instant catalog filtering for **ArcadeVerse (Nexus Spring of Code – Winter Edition 2026)**.

## ⚡ Overview
Provides a streamlined mechanism for users to mark games as favorites directly from the games catalog or player modal. Favorites are synchronized in `localStorage` and filterable through a dedicated "Favorites" category pill with an interactive count badge.

## 🛠️ Features
- **One-Click Heart Toggle**: Responsive heart button positioned on game cards with instant visual glow states.
- **Dedicated Filter Pill**: Quick-filter tab in catalog showing live count of saved games (`Favorites (X)`).
- **Graceful Empty State**: Custom empty-state banner prompting players to bookmark games when none are saved.
- **Zero-Dependency Local Storage**: Preserves saved favorites across browser sessions and tab reloads.
